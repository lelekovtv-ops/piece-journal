# журнал piece — приложение для iPhone

Нативное приложение (Swift + WKWebView): открывает блокнот на весь экран, как
обычное приложение. Записи общие с веб-версией (через GitHub), так что телефон и
компьютер работают вместе. Ставится **бесплатной подписью**, **только тебе**, в
App Store ничего не выкладывается.

## Что нужно один раз
- **Mac** с установленным **Xcode** (бесплатно из Mac App Store).
- **iPhone** и кабель (первый раз — по кабелю; дальше можно по Wi-Fi).
- Обычный **Apple ID** (тот же, что на телефоне). Платный аккаунт разработчика
  НЕ нужен.

---

## Сборка — быстрый путь (рекомендую)

Проект уже собран и лежит в этой папке — просто открой его:

```bash
cd ~/Desktop/piece-journal/ios
open PieceJournal.xcodeproj
```

При первом запуске Xcode попросит согласиться с лицензией — согласись (это
делается один раз). Дальше — раздел **«Подписать и запустить»** ниже.

> Если когда-нибудь поменяешь `project.yml`, пересобрать проект можно так:
> `brew install xcodegen` (один раз) → `xcodegen` в этой папке.

## Сборка — ручной путь (с нуля, если хочешь сам)

1. Xcode → **File → New → Project… → iOS → App** → **Next**.
   - Product Name: `PieceJournal`
   - Interface: **SwiftUI**, Language: **Swift**
   - Сохрани куда угодно.
2. В новом проекте замени содержимое файлов на файлы из папки `ios/Sources/`:
   - `PieceJournalApp.swift` → возьми из `Sources/PieceJournalApp.swift`
   - `ContentView.swift` → возьми из `Sources/ContentView.swift`
3. Иконка: открой `Assets.xcassets` → `AppIcon` и перетащи туда
   `Sources/Assets.xcassets/AppIcon.appiconset/icon-1024.png`
   (в слот «1024pt» / «Single Size»).
4. (необязательно) Чтобы открывалось только вертикально: target → **General →
   Deployment Info → Device Orientation** → оставь только **Portrait**.

## Подписать и запустить

1. Слева выбери синий проект **PieceJournal** → target **PieceJournal** →
   вкладка **Signing & Capabilities**.
2. Поставь галочку **Automatically manage signing**.
3. **Team** → выбери свой Apple ID. Если его нет в списке → **Add an Account…**
   → войди своим Apple ID → выбери появившийся **(Personal Team)**.
4. **Bundle Identifier** поменяй на свой уникальный, например:
   `com.alex.journal` (любой, лишь бы не повторялся).
5. Подключи iPhone кабелем. Вверху Xcode, где выбор устройства, выбери **свой
   iPhone** (не симулятор).
6. Нажми **▶ Run** (⌘R). Xcode соберёт и поставит приложение на телефон.

### Первый запуск на телефоне
Появится «Untrusted Developer» — это нормально для бесплатной подписи:
**Настройки → Основные → VPN и управление устройством → [твой Apple ID] →
Доверять**. После этого открывай иконку «журнал» с рабочего стола.

## Про срок 7 дней
Бесплатная подпись действует **7 дней**. Через неделю приложение перестанет
открываться — просто снова подключи телефон к Mac, открой проект и нажми **Run**:
оно продлится ещё на 7 дней. Данные при этом не теряются.

**Чтобы не делать это вручную** — поставь **AltStore** (altstore.io): он
переподписывает приложение в фоне сам, пока твой Mac иногда в той же сети.
Разовая настройка, дальше забываешь про 7 дней.

## Обновления
- **Записи** синхронизируются сами — что напишешь на телефоне через «Записать» и
  закоммитишь, появится на компьютере, и наоборот.
- **Само приложение** (новые функции блокнота) — обнови репозиторий
  (`git pull` в `~/Desktop/piece-journal`) и снова нажми **Run**.

## Если что-то не так
- «Unable to install» / ошибка bundle id → поменяй **Bundle Identifier** на
  другой уникальный.
- Ошибка подписи → проверь, что в **Team** выбран твой **(Personal Team)**, а не
  пусто.
- Белый экран → проверь интернет (приложение грузит блокнот с сайта при первом
  открытии).
